# 독립 모형 3개

같은 근거 요약과 시간 예산만 받고, 서로의 결과를 보지 않은 채 각 모형 담당 에이전트가 작성·실행한 모형이에요. 비교 결과는 [4부 5절](../../report/04_방법과_검증.md#5-독립-모형과의-비교)에 있어요.

| 파일 | 관점 |
|---|---|
| `M1_physiology.py` | 생리 중심: 수면압·일주기 문턱(2과정 모형), 평형으로 수렴하는 수면부채, 블록 피로, 저노력 이동, 느린 누적 피로 |
| `M2_learning.py` | 학습과학·과제 배치 중심: 과제 4종(새 학습·문제풀이·인출·모의)의 효율·관여·포화·부호화·저노력 이동, 배치 최적화 |
| `M3_minimal.py` | 최소·회의적: 하루 안 저하의 네 가지 모양(선형·볼록·경첩·포화)과 넓은 가정 스윕 |
| `results_summary.json` | 각 모형이 보고한 구조 요약, 수식, 모수, 시간별 표, 임계 시간, 일정 비교, 최적화, 민감도, 견고한/취약한 결론, 자기 비판 |

코드 안의 입출력 경로는 작성 당시의 임시 작업 폴더를 가리켜요. 다시 실행하려면 경로를 이 저장소에 맞게 바꿔야 해요. 이 모형들의 수치는 보고서의 권장안을 정하는 데 직접 쓰지 않았고, 통합 모형(`../study_model.py`)의 구조적 불확실성을 가늠하는 데 썼어요.
