# 「건축」과 「여행의 미래」 — 비교 비평 기록

종합 판정: 「여행의 미래」의 근소한 우세. 인식적 생산성에 관한 독해와 평가 비중에 의존하는 조건부 비교 판정이다.

이 기록은 제공된 두 시와 평가 절차를 바탕으로 작성했다. 시의 저자나 작품 밖의 평판은 판정 근거에 포함하지 않았다. 두 시가 이미 함께 제시되어 있었으므로, 사전등록과 독립 노출을 실제로 수행한 기록은 아니다. 각 단계의 파일은 생성 이후 수정하지 않았다. 가중치 시험은 축별 판정을 고정한 계산이며 비평 판단의 객관성을 증명하지 않는다.

> 00~09단계는 두 시의 원문이 이 저장소에 없는 상태에서 인용 단편만으로 검증할 수 있었다. 원문 확보 뒤의 정정과 축별 재심은 [`10-audit.md`](10-audit.md)에 있다. 앞 단계를 읽을 때는 함께 읽어야 한다.

## 단계 파일

각 파일은 기록이 거친 단계의 순서대로 놓여 있다. 뒤 단계는 앞 단계를 고쳐 쓰지 않고 그 위에 판정을 얹는다.

| 파일 | 단계 |
|---|---|
| `00-criteria.md` | 평가 기준과 가중치 — 이후 단계에서 바꾸지 않는다 |
| `01-close-reading-geonchuk.md` | 「건축」 분리 정독 |
| `02-close-reading-yeohaeng.md` | 「여행의 미래」 분리 정독 |
| `03-genre-vs-performance.md` | 장르 차이와 수행 차이의 분리 |
| `04-axis-comparison.md` | 축별 비교 판정과 1회 종합 |
| `05-robustness.md` | 가중치 강건성 시험 |
| `06-adversarial-review.md` | 적대적 검토 |
| `07-defect-classification.md` | 결함 분류와 해소 조건 |
| `08-self-audit.md` | 자기 판정 감사 |
| `09-final-verdict.md` | 최종 판정과 개작 방향 |
| `10-audit.md` | **원문 확보 후의 사후 감사 — 정정과 축별 재심** |
| `11-meta.md` | 이 비평문 자체에 대한 평가 |
| `12-review-of-review.md` | 검토 작업 자체에 대한 평가 — 뒤늦게 확인한 기록의 결함과 검토 자신의 오류 |
| `13-counter-essay.md` | 기록의 비평 철학에 대한 반박문 (한쪽 편을 드는 글) |

`../RECORD.md`는 같은 내용을 하나로 이은 통합본이다. `../tools/weights.py`는 05단계의 수치를 재계산한다.
