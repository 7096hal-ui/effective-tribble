# 근거표: 이 보고서가 인용하는 출처와 검증 상태

작성 기준일: 2026-09-24. 검증은 이 날짜에 웹 검색 결과(초록, 학술 색인, 출판사·PubMed·ERIC 페이지 요약)로만 했어요. 네트워크 정책 때문에 논문 원문 페이지(doi.org, PubMed 본문, 출판사 원문 등)는 열 수 없었어요. 그래서 아래 "수치 확인"도 원문 표·그림이 아니라 초록 또는 색인 요약 수준의 확인이에요.

## 표기

| 표기 | 뜻 |
|---|---|
| **수치 확인** | 독립 검증 에이전트가 초록·학술 색인 검색 결과에서 인용 수치를 직접 봤음 |
| **서지 확인** | 논문의 존재·저자·연도·학술지는 확인했지만 인용 수치는 보지 못함. 본문에서는 방향만 인용해요 |
| **2차 확인** | 수치를 보도자료·기사·인용 논문 같은 2차 자료에서만 봤음 |
| **조사 단계 확인** | 1차 조사 에이전트가 검색 결과에서 봤다고 보고했지만, 독립 재검증은 하지 못함 |
| 직접 / 간접 / 배경 | 질문(장기간 하루 8~14시간 공부의 시간별 학습성과)과의 거리. "직접"도 대부분 관찰 연구예요 |

## 7. 검증 과정에서 걸러 낸 주장

- Mander(2011)의 "낮잠 집단이 20%p 높았다"는 수치는 보도자료에만 있어 인용하지 않았어요.
- Wiehler(2022)의 "6.25시간"은 두 번 검색해도 확인되지 않아 "대략 하루 근무 분량"으로만 썼어요.
- Roediger & Karpicke(2006)의 40·56·61%, Szpunar(2013)의 19·39·41%는 1차 조사에서 봤다고 보고됐지만 독립 재검증에서 확인되지 않아 방향만 썼어요.
- Murray(2025)의 수학 인출연습 g=0.18, Weng(2025)의 7일 g=0.27은 재검증에서 확인되지 않았어요.
- Cousins(2019)는 "낮잠이 벼락치기보다 낫다"가 아니라 "낮잠과 같은 시간의 추가 공부가 비슷했다"로 고쳐 썼어요.
- 1차 조사 단계에서 일부 검증 에이전트가 이 세션의 허용 범위 밖 GitHub 저장소를 검색해 초록 사본을 찾은 적이 있어요. 그렇게 얻은 확인은 이 표의 검증 상태에 반영하지 않았어요.
- 기숙학원의 일과표, 가오카오 재수생, 일본 로닌 관련 학술 근거는 찾지 못했어요.
