# 「건축」과 「여행의 미래」 — 비교 비평 기록

두 편의 한국 현대시를 작품 밖의 명성 없이, 고정된 기준으로 비교한 기록이다.

**종합 판정: 「여행의 미래」의 근소한 우세.** 인식적 생산성에 관한 독해와 평가 비중에 의존하는 조건부 판정이다.

## 무엇이 들어 있는가

- [`RECORD.md`](RECORD.md) — 통합 기록 전문
- [`criticism/`](criticism/) — 같은 내용을 거친 단계 순서대로 나눈 파일 (기준 → 분리 정독 → 축별 비교 → 강건성 → 적대적 검토 → 결함 분류 → 자기 감사 → 최종 판정 → 사후 감사)
- [`tools/weights.py`](tools/weights.py) — 강건성 시험의 수치를 재계산하는 스크립트

## 시 원문이 없는 이유

이 저장소에는 두 시의 전문이 들어 있지 않다. 저작권이 있는 작품이고, 기록이 판정 근거로 쓴 단편 인용만으로 논증을 따라갈 수 있도록 썼기 때문이다. 인용된 문구가 실제 원문과 일치하는지는 이 저장소만으로 확인할 수 없다.

## 수치를 직접 확인하려면

```
python3 tools/weights.py
```

축별 판정을 고정한 채 가중치 배분만 바꾼 아홉 가지 시험을 재계산한다. 출력은 `criticism/05-robustness.md`의 표와 일치해야 한다.

## 이 기록이 하지 않은 것

- 사전등록과 독립 노출: 두 시가 이미 함께 제시되어 있었으므로 실제로 수행하지 않았다.
- 객관성 증명: 가중치 시험은 축별 판정을 고정한 계산이며, 비평 판단 자체의 타당성은 증명하지 않는다.
- 저자·문학사·평판의 사용: 판정 근거에서 배제했다.
