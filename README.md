## 한국주식 26종목 멀티에이전트 리서치 (2026-09-21, 개정판 v2)

1년·3년·5년 총주주수익률(TSR) 기준으로 26개 한국 상장종목을 순위화한 기관투자자급 리서치.
기대수익률 순위, 위험조정(Forward Sortino) 순위, 균형형 종합순위를 각각 제시한다.

- 🔬 [정량 분석 코드와 재현 방법](analysis/README.md)
- 📋 [기준 주가·2025년 실적 검증 원장](analysis/price-sources.md)

### 요약

| 기간 | 균형형 종합 1위 | 기대수익률 1위 | 위험조정 1위 |

세 기간 일관 상위: 화신 · 삼성에피스홀딩스 · 현대차 · 이수페타시스 · 현대모비스

### v2에서 무엇이 바뀌었나

초판(v1)은 26종목 중 12종목의 재무를 교차검증하지 못한 상태에서 산출되었다.
v2에서 26종목 전부의 2025년 실적·시가총액·희석요인을 검증한 결과 순위가 광범위하게 바뀌었다.

| 종목 | v1 → v2 (1년) | 이유 |
|---|---|---|
| 한중엔시에스 | 6위 → 24위 | 순이익 20.9억(−86.3%), PER 약 291배 |
| 인텔리안테크 | 2위 → 19위 | PER 약 100배, 영업이익률 3.7%, 영업현금 적자 |
| 서진시스템 | 15위 → 26위 | 순손실 1,024억, 재고 8,497억(매출의 77%) |
| 쎄트렉아이 | 18위 → 5위 | 영업이익 101.8억 흑자전환, 수주잔고 5,690억 |
| 삼성바이오로직스 | 14위 → 3위 | 기준가 정정 + CVaR −30.3%의 얕은 하방 |
| 화신 | 11위 → 4위 | 영업이익 1,024억(+56.9%), 추정 PER 약 4배 |

신뢰도 '낮음' 종목: **12개 → 0개**. 자세한 내역과 본 보고서가 스스로 교정한 네 가지 방법론 오류는 보고서 7부에 있다.
