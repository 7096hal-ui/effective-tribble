# effective-tribble

## 한국주식 26종목 멀티에이전트 리서치 (2026-09-21, 개정판 v3)

1년·3년·5년 총주주수익률(TSR) 기준 26개 한국 상장종목 순위화.
기대수익률 순위, 위험조정(Forward Sortino) 순위, 균형형 종합순위를 각각 제시한다.

- 🔬 [정량 분석 코드와 재현 방법](analysis/README.md)
- 📋 [기준 주가·실적 검증 원장](analysis/price-sources.md)

### 요약

**세 기간 일관 상위**: 이수페타시스 · 현대모비스 · 인텔리안테크 · 고영 · 현대차

### 개정 이력

| 버전 | 검증 범위 | 결과 |
|---|---|---|
| v1 | 12종목 미검증 | 신뢰도 '낮음' 12종목 |
| v2 | **2025년 연간 실적** 26종목 | 신뢰도 '낮음' 0종목. 순위 광범위 변동 |
| **v3** | **2026년 상반기 실적** 24종목 + 포렌식 4건 + 유동성 | **v2 판단의 상당수가 뒤집힘** |

### v3에서 뒤집힌 것

| 종목 | v2 → v3 (1년) | 이유 |
|---|---|---|
| 엘앤씨바이오 | 25위 → **8위** | 순손실 1,291억이 CB 파생평가손+영업권 손상의 **전액 비현금 손실**로 규명. 영업현금흐름 −57억→+122억. 1H 매출 +80.6% |
| 인텔리안테크 | 19위 → **3위** | 2025년 OPM 3.7% → 2Q26 **7.3%로 두 배**, 영업이익 +304%, 국방 첫 수주 409억 |
| 선익시스템 | 7위 → **23위** | **1H 매출 363억**(2025년 연간 5,158억의 7%), 영업손실 −87억 |
| 고영 | 18위 → **4위** | 1H 영업이익 **+328.1%**, 순이익 314억 흑자전환. PER 154배 → 약 30배 |
| 쎄트렉아이 | 5위 → **19위** | 창립 최대 수주잔고에도 1Q **적자전환**, 2Q 영업이익 −32.5% |

**핵심 교훈**: 연간 실적은 이미 9개월 지난 과거다. 수주잔고는 이익이 아니다. 순손실이 반드시 나쁜 것도, 흑자가 반드시 좋은 것도 아니다.
