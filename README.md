# 「건축」과 「여행의 미래」 — 비교 비평 기록

두 편의 한국 현대시를 작품 밖의 명성 없이, 고정된 기준으로 비교한 기록이다.

**종합 판정: 「여행의 미래」의 근소한 우세.** 원문 확보 뒤의 재심에서도 방향은 유지되나, 여섯 축이 모두 근소 판정이고 가장 무거운 두 축이 서로 반대로 갈린다. 종합은 사실상 A축(언어의 필연성) 하나에 걸려 있다.

## 무엇이 들어 있는가

- [`RECORD.md`](RECORD.md) — 통합 기록 전문
- [`criticism/`](criticism/) — 같은 내용을 거친 단계 순서대로 나눈 파일 (기준 → 분리 정독 → 축별 비교 → 강건성 → 적대적 검토 → 결함 분류 → 자기 감사 → 최종 판정)
- [`criticism/10-audit.md`](criticism/10-audit.md) — **원문 확보 후의 사후 감사.** 인용 대조에서 나온 정정 11건, 여섯 축의 재심, 급소의 이동. 00~09단계를 읽을 때 함께 읽어야 한다.
- [`tools/weights.py`](tools/weights.py) — 강건성 시험의 수치를 재계산하는 스크립트

## 시 원문이 없는 이유

이 저장소에는 두 시의 전문이 들어 있지 않다. 권리 관계를 확인하지 않은 작품이므로 공개 저장소에 싣지 않았다. 기록은 판정 근거로 쓴 단편 인용만으로 논증을 따라갈 수 있도록 썼다.

원문 대조는 10단계에서 수행했고 그 결과가 [`criticism/10-audit.md`](criticism/10-audit.md)에 있다. 다만 대조에 쓴 원문 자체가 저장소에 없으므로, 대조 결과를 이 저장소만으로 재확인할 수는 없다.

## 수치를 직접 확인하려면

```
python3 tools/weights.py
```

두 판정 집합(04단계의 원래 판정, 10단계의 재심 판정) 각각에 대해 가중치를 흔드는 시험과 축별 판정을 흔드는 시험을 재계산한다. 원래 판정의 출력은 `criticism/05-robustness.md`의 표와, 재심 판정의 출력은 `criticism/10-audit.md` §4와 일치해야 한다.

## 이 기록이 하지 않은 것

- 사전등록과 독립 노출: 두 시가 이미 함께 제시되어 있었으므로 실제로 수행하지 않았다.
- 객관성 증명: 가중치 시험은 축별 판정을 고정한 계산이며, 비평 판단 자체의 타당성은 증명하지 않는다. 수치는 합계 100으로 환산한 기준 지지량이지 작품의 점수가 아니다.
- 저자·문학사·평판의 사용: 판정 근거에서 배제했다.
