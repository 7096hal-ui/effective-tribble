## R5. 조정자 잠정표의 변화와 판정 부호의 역전
- **기존 주장(표적 재독 전 조정자 잠정표)**
  - 값: A 0, B 0, C −1, D +1, E −1, F 0. S = −0.1로 「여행의 미래」 근소 우세.
  - 축 B의 0은 R4의 과장("거의 모든 연 경계")에 일부 기대고 있었다. 과장을 정정한 뒤에는 +1로 되돌릴지 검토했다.
- **새 주장(최종)**
  - 값: A 0, B 0, C 0, D +1, E −1, F 0. S = +0.1로 「건축」 근소 우세.
- **변경 근거**
  - 축 C, −1에서 0으로
    - 1차 두 심사자가 「건축」을 낮게 본 근거 가운데 '익숙함'은 작품 밖 비교, '추상'은 감각 우대라서 무효다(Q 4번 유효).
    - 조정자 자신이 −1을 준 근거에는 '선언된 등식 대 암시된 이미지'라는 표현 방식의 차이가 섞여 있었다. 이는 규약 1.3의 설명/암시 자동 우대에 해당한다(TC_2 지적 수용).
    - 무효 근거를 빼고 남는 차이는 「여행의 미래」 연결망의 폭과 「건축」 개념 반전의 깊이 사이의 교환이다. 규약 C만으로는 이 교환의 우열을 정할 수 없다.
  - 축 B, 0 유지
    - R4 정정 뒤에도 소리 목록 구간(여18~32), 머리 명사 지연(여41~45), 정차의 연 구분(여53~54), 연 길이의 확대(1행 연 → 8행 연 → 산문 행)는 텍스트 사실로 남는다.
    - 「건축」에도 설계 비참여 구간(건07 중반)과 틀의 단조로움이라는 비용이 있다.
    - 두 재독자는 사실에 합의했다. 판단이 갈린 곳(0과 +1)은 '고른 설계'와 '조밀한 형식 사건' 중 무엇을 더 무겁게 보느냐였다. 규약 B는 둘 중 어느 것도 우대하지 않는다.
- **판정 영향**
  - 종합 부호가 「여행의 미래」 쪽에서 「건축」 쪽으로 바뀌었다.
  - 바뀐 원인은 축 C 한 곳이다. 축 C를 −1로 되돌리면 다시 역전되므로, 이 축이 최종 판정의 핵심 전제 가운데 하나다(audit.md).
