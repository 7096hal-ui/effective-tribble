## 실행 형태
- 조정자: 이 대화의 주 모델(Claude Code 원격 세션).
- 하위 작업: Claude Code의 Workflow 도구가 띄운 하위 에이전트. 각 에이전트는 조정자 대화를 상속하지 않고, 조정자가 생성한 프롬프트 하나만 입력으로 받는 별도 컨텍스트에서 실행된다. 모든 하위 에이전트는 같은 모델 계열이므로 **컨텍스트 독립은 확보했으나 모델 독립은 아니다**. 두 비교 심사자의 일치는 독립 증거 두 개로 세지 않는다.

- 생성된 프롬프트 전문: `run/prompts/*.txt`. 워크플로 스크립트: `run/phase1_workflow.js` 등.
