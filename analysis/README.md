# 분석 재현 방법 (v3)

`reports/korean-equity-26-multiagent-research-2026-09-21.md`의 정량 부분을 재현하는 코드다.

| 파일 | 역할 |
|---|---|
| `engine.py` | 몬테카를로 엔진. 시나리오 → TSR 분포 → Sortino/CVaR/백분위 종합점수 |
| `model.py` | 26종목 × 3기간 시나리오 가정. 끝에 `S_LIQ`(유동성 위험 반영본)를 생성 |
| `liquidity.py` | 일평균 거래대금 → 4단계 등급 → 변동성·영구손실확률 조정 |
| `adtv.py` | 종목별 일평균 거래대금 실측치/추정치 |
| `run.py` | 순위 산출 및 콘솔 출력 |
| `tables.py` | 보고서용 표와 민감도 분석 생성 |
| `price-sources.md` | 기준 주가·2025년 실적·2026년 상반기 실적 검증 원장 |

## 실행

```bash
pip install numpy
python3 run.py      # 기간별 순위표
python3 tables.py   # tables.md 생성
```

## 설계상의 주의점 (모두 실제로 교정한 오류에서 나왔다)

1. **시나리오 주당가치 `px`는 조건부 중앙값이다.** 평균보존형 잔차 `exp(σz − σ²/2)`를 쓰면 중앙값이 `exp(−σ²/2)`만큼 눌려 시나리오 분산과 잔차 분산에 위험이 이중 반영된다. 중앙값 보존형 `exp(σz)`를 쓴다.
2. **`e_ann`은 `(1 + E[누적])^(1/T) − 1`이다.** `E[R^(1/T)] − 1`(=`e_ann_alt`)은 젠슨 효과로 왜곡분포에 이중 벌점을 준다(케이엠더블유 5년은 기대누적 +22.7%인데 E[연환산]이 −5.5%로 부호가 뒤집혔다).
3. **경기순환주는 저점 이익에 높은 PER, 고점 이익에 낮은 PER을 적용하지 않는다.** 대칭이어야 한다. 이 원칙을 삼성전자·SK하이닉스에는 적용하고 선익시스템·고영에는 적용하지 않았던 것이 v2·v3의 교정 대상이었다.
4. **유동성은 기대수익률이 아니라 위험에 반영한다.** TSR 정의가 "세전·수수료 차감 전"이므로 거래비용을 기대 TSR에서 빼면 정의 위반이다. `liquidity.apply()`는 기말 주당가치를 건드리지 않고 잔차 변동성(×1.00~1.20)과 영구손실확률(+0.0~1.2%p)만 조정한다.
5. **기간이 다른 Sortino를 직접 비교하지 말 것.** 연환산 수익률의 분산이 시간 평균으로 축소되어 장기 Sortino가 구조적으로 높게 나온다.
6. 무위험수익률은 2026-09-18 국고채(1년 3.976% / 3년 4.034% / 5년 4.221%).
