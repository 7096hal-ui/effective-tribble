# 분석 재현 방법

한국주식 26종목 멀티에이전트 리서치(`reports/korean-equity-26-multiagent-research-2026-09-21.md`)의
정량 부분을 재현하기 위한 코드다.

| 파일 | 역할 |
|---|---|
| `engine.py` | 몬테카를로 시뮬레이션 엔진. 시나리오 → TSR 분포 → Sortino/CVaR/백분위 종합점수 |
| `model.py` | 26종목 × 3기간 시나리오 가정(확률, 기말 주당가치, 누적 주당 현금환원, 잔차 변동성, 영구자본손실 확률) |
| `run.py` | 순위 산출 및 콘솔 출력 |
| `tables.py` | 보고서용 표와 민감도 분석 생성 |
| `price-sources.md` | 종목별 기준 주가와 그 근거(검색 기반 수집 원본) |

## 실행

```bash
pip install numpy
python3 run.py        # 기간별 순위표 출력
python3 tables.py     # tables.md 생성 (보고서 삽입용)
```

## 설계상의 주의점

- `simulate()`의 시나리오 주당가치(`px`)는 **해당 시나리오의 조건부 중앙값**으로 해석한다.
  평균보존형 잔차(`exp(σz − σ²/2)`)를 쓰면 중앙값이 `exp(−σ²/2)`만큼 체계적으로 눌려
  시나리오 분산과 잔차 분산에 위험이 이중 반영된다. 따라서 중앙값 보존형(`exp(σz)`)을 쓴다.
- `metrics()`의 `e_ann`은 `(1 + E[누적])^(1/T) − 1`이다. `E[R^(1/T)] − 1`(= `e_ann_alt`)은
  젠슨 효과로 왜곡분포에 이중 벌점을 주므로 순위 산정에 쓰지 않는다.
- 무위험수익률은 2026-09-18 국고채 수익률(1년 3.976% / 3년 4.034% / 5년 4.221%)이다.
- 기간이 다른 Sortino를 직접 비교하지 말 것. 연환산 수익률의 분산이 시간 평균으로 축소되어
  장기 Sortino가 구조적으로 높게 나온다.
