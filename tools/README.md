# tools

## weights.py

강건성 시험을 재계산한다. 가중치는 `AXES`에, 축별 판정은 두 집합으로 나뉘어 있다.

- `RECORD` — 원문 없이 인용 단편만으로 내린 04단계의 축별 판정
- `REVIEW` — 원문 확보 뒤 독립 심사 2인 + 조정 1인으로 다시 내린 10단계의 축별 판정

```
python3 tools/weights.py
```

두 판정 집합 각각에 대해 출력한다:

1. 강건성 표와 같은 아홉 행 (기본, 전부 균등, F를 단독 최대로, A~F 각 축 제거)
2. F와 A·B를 각각 맞바꾼 두 경우
3. **판정을 흔드는 시험** — 축 하나의 판정을 다른 값으로 바꿨을 때의 결과. 기록의 05단계가 수행하지 않은 시험이며, 급소가 어디인지는 이쪽이 결정한다.

끝에 경계값을 덧붙인다. `RECORD` 집합에서는 C축 가중치를 낮출 때의 경계(C=5에서 대등), `REVIEW` 집합에서는 A축 가중치를 낮출 때의 경계(A=5에서 대등)다.

수치는 합계 100으로 환산한 **기준 지지량**이다. 작품의 절대 점수도, 우수할 확률도 아니다. 유리수(`fractions.Fraction`)로 계산한 뒤 마지막에만 반올림하므로 표의 소수 둘째 자리가 그대로 재현된다.
