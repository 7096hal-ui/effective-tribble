# tools

## weights.py

`criticism/05-robustness.md`의 강건성 시험을 재계산한다. 축별 판정(우세/대등)은 `AXES`에 고정되어 있고, 스크립트는 가중치 배분만 바꾼다.

```
python3 tools/weights.py
```

출력:

1. 기록의 강건성 표와 같은 아홉 행 (기본, 전부 균등, F를 단독 최대로, A~F 각 축 제거)
2. F와 A·B를 각각 맞바꾼 두 경우
3. C축 가중치를 0부터 낮춰 판정이 뒤집히는 경계
4. 기록이 수행하지 않은 시험 — 대등으로 둔 축 하나를 한쪽 우세로 돌렸을 때의 결과

수치는 합계 100으로 환산한 **기준 지지량**이다. 작품의 절대 점수도, 우수할 확률도 아니다. 유리수(`fractions.Fraction`)로 계산한 뒤 마지막에만 반올림하므로 표의 소수 둘째 자리가 그대로 재현된다.
