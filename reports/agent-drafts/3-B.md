## 4. Q5 판단 근거
**결론(정성):** 통합과학 수준으로 입학해 기초부터 성실히 공부할 경우, "따라가기"(이수, F와 학사경고 회피)는 **가능하다는 쪽이 근거와 합치한다.** 다만 이것은 조건부다. 상위권 성적까지 가능한지에 대한 근거는 없다. 위험이 큰 구간은 1학년 생리학과 2학년 약리·병태생리다.
- 불리함은 실재한다. 과학 배경이 있으면 합격 오즈가 높고(#1), 화학 미학습자는 저성취 비율이 높다(#4).
- 그러나 짧은 브리징만으로도 격차가 줄었다(#4, #5). 3.5개월 선행은 이 개입들(3~5일)보다 훨씬 길다. 효과가 비례한다는 근거는 없다 [추정].
- 성숙연령 학생의 성취가 평균적으로 높다는 근거가 있다(#13, #14). 한계는 정의 불일치와 호주 표본이다.
- 성과 예측력은 과거 이수 배경보다 과학 자기효능과 학습행동 쪽에 근거가 더 많다(#2, #6, #15).
- 국내 직접 근거는 없다. 국내 근거는 질적 연구와 비간호 연구(#16–23)뿐이다.

| 가능 조건 | 불가능·고위험 조건 |
|---|---|
| 입학 전 화학·생명 기초 선행(범위는 Q7 담당 에이전트) | 선행 없이 첫 학기에 따라잡기 + 학기 중 장시간 근로 |
| 강의 후 24~48시간 안에 인출(백지 회상, 문항 풀이) + 간격반복을 학기 내내 상시 운영 | 재독·필기·형광펜 위주로 대량 암기 시도 |
| 의학용어(어근·접두사·접미사) 선행으로 언어 강점을 직접 활용 [추정] | 생리 개념이 빈 채로 2학년 약리·병태생리에 진입 |
| 학기 중 근로 최소화 | 학사경고 누적. 몇 회에 제적인지는 대학 학칙 확인 필요 |

## 5. Q6 근거
**'성공적'의 조작적 정의 후보와 기저율 통계 존재 여부**
| 정의 | 내용 | 대응하는 기저율 통계 |
|---|---|---|
| D1(최소) | 1~2학년 전공기초(해부·생리·생화·미생물·병리·약리)에서 F·재수강 0회, 학사경고 0회 | **없음.** 간호학과 F·학사경고 비율은 공시·연구 모두 미발견 |
| D2(과제의 예시) | D1 + 해당 과목 전부 B0 이상 | **없음.** 구조적 상한만 있다: "A+B 70% 이내" 규정을 엄격히 적용하면 과목당 B 이상은 수강생의 최대 70%이고, 6~8과목을 모두 충족하는 비율은 과목 간 상관이 완전하지 않은 한 70%보다 낮다(논리적 귀결). 실제 분포는 대학별 완화 규정이 있어 미확인 |
| D3(강) | 전공기초 평점 B+ 이상 또는 학과 상위 절반 | 없음 |

국외 참조값(노르웨이 불합격 21–24%, 합격 91%, 미국 A&P D/F/철회 27%, 커뮤니티칼리지 성공률 약 50%)은 평가 체계가 달라 **한국 4년제 상대평가에 옮겨 쓰면 안 된다.**

**정성 판단 (숫자는 산출하지 않음):** 직접 기저율이 없어 근거에 기반한 확률을 낼 수 없다.
- **D1:** 가능성이 높은 쪽. 근거로 든 보건·간호 계열 중도탈락 2~3%대와 국시 95%는 지방 사립 간호의 이수율로 간접 연결한 것이다 [추정].
- **D2:** 불확실(중간). 동기는 평균적으로도 보장받지 못하는 기준이다(구조적 상한 70%).
  - 불리 요인: 동기들의 고교 과학 이수 우위 [추정], 암기 약점, 시각처리 약점, 처리속도 평균
  - 유리 요인: 성숙연령, 언어·메타인지 강점, 3.5개월 선행
  - 두 방향이 상쇄되므로 순 효과를 판단할 근거가 없다.
- 상위 문서가 숫자를 꼭 써야 한다면, 근거가 있는 것은 "D2 상한 70%"뿐이라고 명시하라.
